# P-004 — ذيل الأدلة في كل تقرير

> يُلصق في **آخر كل Brief** لأي وكيل. بدونه التقرير ناقص والكومِت مرفوض.
> المرجع: `docs/GOVERNANCE/EVIDENCE.md` · `AGENTS.md` §2.41 (`RULE-N196`).

---

## النص (انسخه كما هو)

```
REPORT SHAPE — لا تسليم بلا دليل:

1) الملفات التي لمستها: قائمة حرفية (مسارات). أي ملف لمسته ولم يُذكر = مخالفة نطاق.
2) قرارات اتخذتها: سطر لكل قرار + سببه.
3) الأدلة — جدول إلزامي:
   | ما قِيس | القيمة | الأمر | المخرج |
   كل قيمة رقمية في تقريرك يجب أن تظهر هنا مع الأمر الذي أنتجها.
4) ما لم أتحقق منه: اكتبه صريحاً + الأمر الذي يثبته. «لم أتحقق» مقبولة، والادعاء الكاذب مرفوض.
5) المخاطر: ما قد ينكسر لاحقاً ولماذا لم تلمسه.
6) قائمة اختبار يدوي عربية: # | الشاشة | الخطوة | النتيجة المتوقعة.
7) السطر الأخير حرفياً:
   لم يُكتب أي اختبار آلي — الاختبار مسؤولية المالك (AGENTS.md §2.31)

ممنوع في التقرير: «تم» · «يعمل» · «كل» · «غالباً» · «يجب أن» — بلا رقم/أمر/مخرج.
```

## كيف يفحصه الـOrchestrator (30 ثانية)

| البند | الفحص |
|---|---|
| النطاق | كل مسار في التقرير داخل الـBrief؟ وإلا: diff مرفوض |
| الأدلة | كل رقم له صف في الجدول؟ وإلا: يُعاد التقرير |
| «لم أتحقق» | موجودة؟ تُسجَّل كبند مفتوح في ملف المهمة |
| قائمة الاختبار | موجودة وبالعربية؟ وإلا: لا تسليم (`RULE-N119`) |
| السطر الأخير | موجود حرفياً؟ وإلا: لا تسليم |
