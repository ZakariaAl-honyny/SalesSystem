# P-003 — التعديل الشامل على النظام (System Sweep)

> يُلصق في **كل موجة > 8 ملفات** أو أي طلب فيه كلمة «كل الشاشات / كل الملفات».
> المرجع: `docs/GOVERNANCE/SYSTEM-SWEEP.md` · `EVIDENCE.md`.

---

## النص (انسخه كما هو)

```
SYSTEM SWEEP — لا «كل» بلا ثلاثة أعداد.

الخطوة 1 — الجرد بالأمر (ممنوع كتابة القائمة يدوياً):
    <command ينتج قائمة الملفات>
    الناتج: N ملفاً — يُسجَّل في MANIFEST.md صفاً صفاً.

الخطوة 2 — الفرز: كل ملف: «داخل» أو «معفى + السبب». الإعفاء بلا سبب = مرفوض.

الخطوة 3 — التقسيم: دفعات ≤ 8 ملفات · ≤ 4 شاشات · مالك واحد لكل ملف.
    لكل وكيل: قائمة ملفات مغلقة (أرقام الصفوف من MANIFEST) — لا مجلدات، لا «وما شابهها».

الخطوة 4 — التنفيذ دفعة بدفعة: بعد كل دفعة ✔ + الدليل + بناء 0 أخطاء.

الخطوة 5 — المطابقة (إلزامية):
    المُكتشَف = داخل + معفى
    داخل      = مُنجَز + متبقٍ
    أي انحراف ⇒ توقّف وأبلغ، لا تعد تجميل الأرقام.

الخطوة 6 — فحص البقايا: البحث عن الأثر القديم يجب أن يُعيد 0 (أو الاستثناءات المعلنة فقط).
    والبحث عن الأثر الجديد يجب أن يساوي عدد «مُنجَز».

الخطوة 7 — الإغلاق: مراجعة واحدة · سجل الحالة محدَّث · كومِت واحد · الأعداد الثلاثة في التقرير.

ممنوع: سكربت يعدّل «كل الملفات» بلا قراءة مخرجاته · تعديل ملفين ثم تعميم الحكم ·
«الباقي متشابه» · إغلاق بلا فحص بقايا.
```

---

## فحص قبول الـOrchestrator

- [ ] `MANIFEST.md` موجود ومملوء بالأمر لا بالذاكرة.
- [ ] مجموع الصفوف = N في الرأس.
- [ ] كل صف إما ✔ أو ➖ (بسبب).
- [ ] `داخل − مُنجَز = المتبقي` والرقم مطابق.
- [ ] فحص البقايا = 0.
- [ ] التقرير يحمل الأعداد الثلاثة + الأمر.
