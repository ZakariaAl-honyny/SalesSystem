## الأدلة (القياس بعد الموجة)

```powershell
Get-ChildItem ".opencode\agents\*.md" | ForEach-Object {
  $t = Get-Content $_.FullName -Raw
  "{0,-24} GENERAL={1} PROJECT={2} ROLE-PROMPTS={3}" -f $_.Name,
    ([regex]::Matches($t,'GENERAL-STANDARDS')).Count,
    ([regex]::Matches($t,'PROJECT-STANDARDS')).Count,
    ([regex]::Matches($t,'ROLE-PROMPTS')).Count
}
```

النتيجة المقيسة: **GENERAL = 1 · PROJECT = 1 · ROLE-PROMPTS = 1 في 11/11 ملفاً** (وكانت 0/0/0 في 10 ملفات، و1 لـ`GOVERNANCE` في المنسّق وحده).

`git diff --numstat` ⇒ **13 سطراً مضافاً · 0 محذوفاً في 11 ملفاً** من `.opencode/agents/**` = 143 سطراً (10 × 13 + 13) — لا حذف، فلا سلوك قديم فُقد.
