# سجل المهام (Task Records) — البروتوكول

> **القاعدة:** كل مهمة = **ملف واحد**. لا مهمة بلا ملف، ولا ملف لعدة مهام. (`RULE-N197`)
> الملف **جزء من المشروع**، يُقرأ قبل أول سطر ويُحدَّث قبل آخر سطر — لا رفاهية.

## 1. التسمية

```
docs/TASKS/TASK-000-TEMPLATE.md          ← القالب (لا يُعدَّل إلا بقانون)
docs/TASKS/TASK-001-<slug>.md            ← مهمة حقيقية
docs/TASKS/INDEX.md                      ← جدول كل المهام
```

`slug` إنجليزي قصير بشرطات: `schema-freeze-law` · `frm-product-enter-nav` · `mock-coverage-auth`.

## 2. حقول الرأس (تُملأ في الدقيقة الأولى)

| الحقل | القيمة |
|---|---|
| `ID` | `TASK-NNN` (تسلسلي، لا يُعاد استخدامه) |
| `العنوان` | جملة واحدة |
| `الحجم` | `S` / `M` / `L` (`RULE-N155`) |
| `المرحلة` | `A` (Mock) · `B` (باك-إند بموافقة) · `—` (تحسين/إصلاح) · `وثائق` |
| `الحالة` | مفتوحة · قيد التنفيذ · مبنية · مراجَعة · بانتظار شهادة المالك · مغلقة · ملغاة |
| `الوكيل المالك` | `ui-agent` / `backend-architect` / … |
| `أثر قاعدة البيانات` | `لا شيء` **أو** `إضافة آمنة — موافقة: <نص+تاريخ>` |
| `التاريخ` | `YYYY-MM-DD` |

## 3. الأقسام (بالترتيب، بلا حشو)

الهدف · خارج النطاق · الملفات (قائمة مغلقة) · العقود · البيت الواحد · الموجات · **الأدلة** · المراجعة · الاختبار اليدوي · القرارات والمخاطر · سجل التغييرات.

## 4. دورة الحياة

```
مفتوحة → قيد التنفيذ → مبنية → مراجَعة → (بانتظار شهادة المالك) → مغلقة
```

- **لا تُغلق** إلا بـ: بناء 0 أخطاء + قسم أدلة مملوء + قائمة اختبار عربي + كومِت + دفع.
- **ملغاة**: سبب + المهمة التي حلّت مكانها. **لا حذف، لا إعادة استخدام رقم.**

## 5. من يكتب؟

**الـOrchestrator وحده** (سبب مقيس: أربعة وكلاء متوازين يكتبون ملفاً واحداً = آخر كتابة تمحو ما قبلها — `RULE-N158`).
الوكيل الفرعي **يقرأ ملفه أولاً**، ويُعيد في تقريره: ملفات لمسها · قرار · دليل مقيس · خطر · ما يجب تسجيله. الـOrchestrator يُدوّنها ثم يبني ثم يكومِت.
**مهمة بلا سجل مُحدَّث = لا كومِت** (بوابة 0e).

## 6. العلاقة ببقية السجلات

| الملف | يحمل |
|---|---|
| ملف المهمة (هنا) | **ماذا فعلنا في هذه المهمة** وبأي دليل |
| `docs/MOCK-COVERAGE.md` | هل الوحدة مؤهلة للمراجعة (حالة نظامية) |
| `docs/SHARED-HOME-REGISTER.md` | أين يعيش الكود المشترك وكم يستهلكه |
| `AGENTS.md` | ما هو **مسموح/ممنوع** أصلاً |
| `docs/CHANGELOG.md` | ماذا تغيّر في المشروع عبر الزمن |

ملف المهمة **لا يكرّر** هذه الأرقام — يُحيل إليها (`RULE-N174`).
