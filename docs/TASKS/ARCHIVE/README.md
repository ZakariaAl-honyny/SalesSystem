# أرشيف ملفات تتبع المهام الكبيرة (`docs/TASKS/ARCHIVE/`)

> **قرار المالك (2026-11-16):** «بعد أي مهمة كبيرة نُخرج ملفها من الطريق — **أرشفة لا حذف**: يختفي من الجدول النشط، وتبقى ذاكرته».
> **القاعدة:** ملف التتبع **يُغلق ثم يُؤرشف** بـ`git mv` إلى هذا المجلد. **الحذف (`git rm`) ممنوع** — لأنه يمسح الأدلة والموافقات وسجل الجولات، فيبدأ الوكيل التالي من الصفر (وهو العيب الذي بُنيت هذه الطبقة لإزالته — `G-07`/`G-08`/`RULE-N202`).

## خطوات الإغلاق الخمس (بالترتيب، بلا تخطّي)

| # | الخطوة | الدليل المطلوب |
|---|---|---|
| 1 | **طابِق الأعداد الثلاثة** في رأس الملف | `المُكتشَف = داخل + معفى` · `داخل = مُنجَز + متبقٍ` · `فحص البقايا grep = 0` (`RULE-N201`) |
| 2 | **جولة إغلاق في §9 (append-only)** | نص الجولة + `commit hash` + من راجع (`code-reviewer`) |
| 3 | **الحالة في الرأس** = `✅ مغلقة` — وكل صفوف لوحة الوكلاء `✅` أو `⬛ معفى + السبب` | لا صف `🔄` باقٍ |
| 4 | **`git mv docs/TASKS/<اسم-المهمة>.md docs/TASKS/ARCHIVE/<اسم-المهمة>.md`** | `git log --follow` يبقى يتابع التاريخ — لا فقد |
| 5 | **حدّث المؤشرات:** `docs/TASKS/ACTIVE.md` → «لا توجد مهمة كبيرة مفتوحة» · صف الأرشيف في `docs/TASKS/INDEX.md` بالمسار الجديد | سطر في سجل المهمة/الجولة |

## ما يبقى في الملف المؤرشف (ولا يُحذف منه شيء)

| المحتوى | لماذا يبقى |
|---|---|
| **الموافقات بنصها وتاريخها** | دليل أن الباك-إند مُصرَّح به (`RULE-N166`) وأن الهيكل لم يُمسّ بلا موافقة (`RULE-N198`) — لا يُعاد بناؤه من الذاكرة |
| **جرد الملفات + حالة كل ملف** | يجيب «ماذا مُسَّ فعلاً؟» بعد شهور |
| **الأدلة (أمر + مخرج)** | يجعل الأرقام قابلة لإعادة القياس لا للتصديق (`RULE-N196`) |
| **سجل `PILOT-n` والعيوب** | يمنع إعادة اختراع نفس العيب في الموجة التالية (`RULE-N186`) |
| **جولات §9** | الذاكرة التي تمنع «البدء من جديد» |

## ممنوع

```text
❌ git rm ملف تتبع   ❌ تفريغ محتواه   ❌ ضغطه إلى ملخص   ❌ نقله إلى مجلد خارج docs/**
```

## كيف يجد الوكيل ملفاً مؤرشفاً

1. `docs/TASKS/INDEX.md` ← صف «مؤرشفة» يحمل المسار الجديد.
2. أو: `Get-ChildItem docs\TASKS\ARCHIVE -Filter *.md` ثم `Select-String` على اسم الميزة/الملف.
3. `git log --follow -- docs/TASKS/ARCHIVE/<file>.md` لأي تغيير تاريخي عليه.
