# مجلد الميزات والمهام الكبيرة (Features)

> **لهذا المجلد:** أي **ميزة** أو **مهمة كبيرة** (L) تُفتح مرة واحدة، ويبقى ملفها **إلى الأبد**.
> كل تعديل مستقبلي عليها **يُضاف** إلى ملفها (جولة جديدة) — **يُمنع البدء من الصفر** (`RULE-N197`).
> هذا المجلد **جزء من المشروع**، لا رفاهية: يُقرأ قبل أول سطر ويُحدَّث قبل آخر سطر.

## متى تُفتح ميزة هنا؟

| الحالة | المكان |
|---|---|
| شاشة جديدة · وحدة جديدة · مسار بيانات جديد · تعميم سلوك على عدة شاشات (≥ 3) · ترحيل/هيكل | **هنا**: `docs/FEATURES/F-NNN-<slug>/` |
| إصلاح صغير · دفعة S (≤ 8 ملفات) · خطأ بناء · تحسين شاشة واحدة | `docs/TASKS/TASK-NNN-<slug>.md` |
| جولة صيانة داخل ميزة موجودة | **ملف جولتها** (`LOG.md`) في مجلد الميزة نفسها |

## الملفات الخمسة (داخل كل مجلد ميزة)

| الملف | المسؤولية الوحيدة | يُقرأ متى |
|---|---|---|
| `README.md` | **اقرأ هذا أولاً**: هوية الميزة · حالتها · ما لا يجوز كسره · أين يعيش كودها | **قبل أي تعديل** |
| `BRIEF.md` | النطاق المغلق: ملفات داخلة · خارج النطاق · العقود · أثر قاعدة البيانات | عند بدء العمل/تسليم وكيل جديد |
| `PLAN.md` | المراحل والموجات وبوابات الشهادة + ما أُنجز من كل مرحلة | عند التخطيط |
| `DECISIONS.md` | كل موافقة وقرار **بالنص والتاريخ** (موافقة المالك · اعتماد الشكل · أي استثناء) | قبل Stage B أو أي تمديد نطاق |
| `LOG.md` | سجل **إضافي فقط (append-only)**: جولة بعد جولة — ماذا تغيّر · الدليل المقيس · الكومِت | عند أي تعديل مستقبلي |

## البروتوكول (ست خطوات، لا تتغيّر)

1. **قبل البدء:** اقرأ `README.md` ثم `BRIEF.md` ثم **الجولة الأخيرة** في `LOG.md`. لا تقرأ المشروع كله.
2. **قبل الـBrief:** الـOrchestrator يحدّث `BRIEF.md` إن تغيّر النطاق، ويُنشئ رقم جولة جديداً في `LOG.md`.
3. **بعد البناء:** تُكتب **الأدلة** (أمر + مخرج) في الجولة نفسها.
4. **بعد المراجعة:** الحكم والملاحظات في `LOG.md` (**أو `DECISIONS.md`** إن كان قراراً).
5. **قبل الكومِت:** `README.md` يُحدَّث فقط إذا تغيّرت **الحالة** أو **«ما لا يُكسر»**. وإلا فلا تلمسه.
6. **أبداً:** لا حذف جولة · لا تعديل جولة قديمة · لا «تنظيف» السجل. التاريخ هو القيمة.

## الترقيم

`F-001` · `F-002` … تسلسلي، **لا يُعاد استخدامه**، ولا يُحذف مجلد ميزة (يُغلق بالحالة `مغلقة — مدمجة`).
