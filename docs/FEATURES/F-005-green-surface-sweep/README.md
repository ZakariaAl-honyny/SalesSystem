## ١) طلب المالك (نصّه)

> «I want to improve UI shape for improve UX — I want the screen color are green or light green and input fields are white color so the inputs fields are clear for end user eyes, like frm*Masters and frmCRUDProductMaster.»

**الشاشة المرجعية المعتمدة:** `frmCRUDCProductMaster` (وما شابهها: `frmCRUDCExpensesMaster` · `frmCRUDCustomerReceiptsMaster` · `frmOpeningStock`) — المالك سمّاها بنفسه «الصحيحة».

## ٢) العيب المقيس (لا من الذاكرة — `RULE-N195`)

**السطح الصحيح (المرجع):** النموذج أخضر `170,220,170` · الأشرطة `235,240,235` · صناديق المجموعة `235,245,235` · الحقول بيضاء `White` ⇒ تباين واضح.
